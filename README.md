## Completed Features ✅
1. **Landing page** (`/`): أعمدة المنصة، صور الصفوف، كاروسيل الكورسات — المسجّلون يُحوَّلون تلقائيًا إلى `/home`
2. **Auth** (`/auth`): تسجيل جديد + دخول + نافذة السياسات — نجاح الدخول يحوّل مباشرة إلى `/home`
3. **Telegram verification bot**:
   - `/start v<code>` للتحقق بالكود، و`/start` بدون كود يعرض زر مشاركة الرقم مباشرة
   - استرجاع كلمة السر: رقم ولي الأمر + الاسم **في رسالة واحدة**
4. **Student Home** (`/home`): الرئيسية / كورساتك / اشتراكاتك / حالتي / **الإعدادات**
   - حارس جلسة + قفل الجهاز (`device_conflict`)
5. **الاشتراك عبر واتساب مباشرة** — زر "اشترك" يفتح واتساب فورًا برسالة جاهزة (**بدون شارة "في انتظار التفعيل"**)
6. **شرائط المحاضرات (Accordion)** 🆕 — داخل الكورس: شريط لكل محاضرة عليه اسمها وسهم جانبي؛ الضغط يفتح فيديوهات وملفات وامتحان المحاضرة (شريط واحد مفتوح في المرة)
7. **صفحة امتحان مستقلة** 🆕 — الامتحان يفتح في صفحة خاصة (`#view-exam`) بهيدر وعنوان وزر خروج، مش أسئلة تحت المحتوى
8. **لوحة الإشراف** 🆕 (`/admin`) — الدخول من زر ⚙️ الإعدادات في واجهة الطالب بكلمة سر `123321`:
   - **إحصائيات**: طلاب / موثّقين / اشتراكات / في الانتظار
   - **الطلاب**: بحث، توثيق/إلغاء، حظر/فك، تصفير الجهاز، حذف
   - **الاشتراكات**: تفعيل/تعطيل/حذف + إضافة اشتراك يدوي (رقم + كورس)
   - **الكورسات**: إضافة/تعديل (سعر، صف، ترتيب، نشر) + إخفاء
   - **محرر شرائط المحاضرات**: إضافة/حذف محاضرات وفيديوهات (رابط يوتيوب يتحوّل ID تلقائيًا) وملفات وأسئلة امتحان بالاختيارات والإجابة الصحيحة

9. **رسوم بيانية للطالب في المنزل** 🆕 — بطاقات (فيديوهات/امتحانات/متوسط الدرجات/أيام مذاكرة) + رسم مشاهدات آخر 7 أيام + منحنى درجات الامتحانات (Chart.js)
10. **تتبع النشاط** 🆕 — تسجيل دخول يومي وفتح فيديوهات ونتائج امتحانات في `student_activity/{phone}`
11. **ملف الطالب في الإشراف** 🆕 — الضغط على أي طالب يفتح مودال فيه: بياناته واشتراكاته + رسوم (فيديوهات يومية 14 يوم / مستواه في الامتحانات %) + جدول آخر الفيديوهات اللي فتحها
12. **رسوم يومية في واجهة الإشراف** 🆕 — 4 رسوم لآخر 14 يوم: دخول الطلاب / طلبات الاشتراك / مشاهدات الفيديو / تسجيلات جديدة
13. **قائمة تشغيل الفيديوهات** 🆕 — تحت المشغل تظهر Playlist بكل فيديوهات المحاضرة والتنقل بينها بضغطة
14. **نظام السؤال الواحد في الامتحانات** 🆕 — سؤال واحد في الشاشة + شريط تنقل سريع أعلى + أزرار السابق/التالي + انتقال تلقائي بعد الاختيار (MCQ 4 اختيارات / صح وخطأ اختيارين / مقالي بمربع كتابة)
15. **تفسير الإجابة بالعربي البسيط** 🆕 — بعد التصحيح يظهر تحت كل سؤال تفسير مختصر "ما قل ودل"
16. **مشغل فيديو محمي** 🆕 — يوتيوب مخفي تمامًا (nocookie + دروع فوق الشعار) + علامة مائية متحركة (اسم الطالب + آخر 3 أرقام من تليفونه) بتظهر وتختفي في أماكن عشوائية
17. **قسم الذكاء الاصطناعي والتلجرام** 🆕 (بدل "محتوى المحاضرات") — يضم:
    - **أدوات المساعدة في البنوك**: تفعيل/قفل الترجمة للعربية وشات AI (موديل 2.5 flash lite) لكل بنك
    - **ملفات المنهج**: رفع محتوى المنهج لكل صف (يغذي تحليل الطالب بالذكاء الاصطناعي)
    - **قسم التلجرام**: نظام كلمات المرور المؤقتة (ساعتين / 3 محاولات / تغيير إجباري)
    - **قسم التحليلات**: أكتر الأسئلة اللي الطلاب بيغلطوا فيها
18. **بنوك الأسئلة المطورة** 🆕 — 6 أوضاع توليد منفصلة تمامًا: اختياري / صح وخطأ (بالعدد المظبوط) / مقالي مباشر / النسخ الفكري (تحليل أسلوب امتحان) / استخراج الأسئلة زي ما هي / نماذج متطابقة الصعوبة (كل نموذج يتحفظ بنك مستقل) + إضافة يدوية لكل نوع + صورة لكل سؤال + تفسير بالعربي
19. **تصحيح المقالي المتساهل** 🆕 — الكلمة الصح ≥70% أو أكثر من 3 حروف مظبوطة تتحسب صح (خوارزمية محلية + AI للحالات الغامضة)
20. **صناعة الكورس المطورة** 🆕 — رفع صورة الكورس من الجهاز (رفع مجزأ أقل من نص ميجا بفواصل متغيرة عبر Firebase) + معاينة صورة يوتيوب لكل فيديو + رفع ملفات على المنصة لكل محاضرة + **نشر / تحديد موعد نشر** لكل محاضرة ولكل كورس (publishAt)
21. **ملف الطالب الموسع** 🆕 — جدول درجات كل الامتحانات مع زر ترتيب (الأحدث/الأعلى/الأقل) + صندوق الأسئلة اللي غلط فيها + تحليل بالذكاء الاصطناعي (اختيار الصف → ابدأ التحليل → صناديق: الدروس وإزاي يذاكرها / نقاط الضعف وحلولها / رسم بياني وإحصائيات)
22. **إصلاح فلتر درجات الامتحانات** 🆕 — القائمة بتتملي من كل الامتحانات اللي ليها نتايج فعلًا (`/api/admin/exam-filters`)
23. **حقوق الملكية** 🆕 — أسفل كل الصفحات: "تصميم وتطوير: فريق عمرو كارم محمود وفريقه"


## 🎨 إعادة تصميم لوحة الإشراف + تجربة الامتحان (آخر تحديث)
1. **تجربة الامتحان الجديدة**: لا انتقال تلقائي — زر "التالي ➡️" فقط، تحذير عند الخروج (📤 تسليم / 🚪 خروج / ↩️ استكمال)، **شاشة نتيجة منفصلة** بحلقة نسبة مئوية + 🔍 مراجعة + 🔄 حاول تاني
2. **واجهة أسئلة مجمّلة**: شريط تقدّم متدرّج، شارة رقم/نوع السؤال (🔤/✔️✖️/✍️)، حروف ملوّنة للاختيارات، أنيميشن، زر تسليم نابض
3. **منشئ الكورسات**: "نبدأ كورس جديد ✨" → كارت مربّع زي كارت الطالب + "أضف صورة" 📷 (رفع من الجهاز) + ID تلقائي
4. **دخول الكورس → مستطيلات المحاضرات**: كل محاضرة مستطيل؛ 3 اختيارات: 🎬 فيديو (معاينة يوتيوب) / 📄 ملف (رفع مجزّأ) / 🏦 بنوك — مع نشر/جدولة لكل محاضرة وكورس
5. **قسم AI/تلجرام بتبويبات داخلية**: 🛠️ أدوات / 📚 منهج / ✈️ تلجرام / 📊 تحليلات
6. **ملف الطالب**: كارت تحليل AI 🧠 فوق صندوق الأسئلة الخاطئة ❌

## 🆕 تحديثات الكورسات والاشتراك (أحدث)

2. **صندوق وصف الكورس 📋**: textarea في منشئ الكورس (التواريخ والتفاصيل) يظهر للطالب في صفحة الكورس تحت الهيدر ("عن الكورس")
3. **الخصم بالنسبة المئوية 🔥**: المستر يكتب السعر + نسبة الخصم % والنظام يحسب السعر النهائي تلقائيًا (مع معاينة فورية)
4. **عدّاد تنازلي للخصم ⏳**: زر "⏰ ضبط وقت الخصم" — الطالب يشوف عدّاد حي على الكارت، وبعد انتهاء الوقت الخصم يختفي تلقائيًا ويرجع السعر الأصلي

## Data Architecture
- **Storage**: Firebase Firestore (REST API) — project `monsieur-mostafa`
- **Collections**: `users/{phone}` (+lastSeenAt), `tg_sessions/{chatId}`, `courses/{id}`, `enrollments/{phone}_{courseId}`, `course_content/{courseId}` (حقل `json`)، `student_activity/{phone}` (حقل `json`: logins/videos/exams)، `question_banks/{id}` (title/group/json=questions)، `exam_results/{phone}_{ts}` (سجل مركزي للدرجات)
- **Content model**: `{lectures:[{id,title,videos:[{id,title,youtubeId,duration}],files:[{id,title,url,size}],exam:{id,title,questions:[...]} | {id,bankId,count,title} | null}]}`
- **امتحان مربوط ببنك**: السيرفر يسحب `count` سؤال عشوائي من البنك لكل طالب عند فتح المحتوى (access=full فقط)
- **قفل المحتوى**: السيرفر يشيل youtubeId/url/questions لو الاشتراك مش active والكورس مدفوع
- **Admin auth**: كلمة سر `123321` — هيدر `x-admin-pass` على كل مسارات الإدارة عدا `/login`

## User Guide
1. الطالب يسجّل ويوثّق حسابه عبر بوت تيليجرام
2. من "كورساتك" يضغط "اشترك" → يفتح واتساب مباشرة برسالة جاهزة للمستر
3. المستر يفعّل الاشتراك من لوحة الإشراف (تبويب الاشتراكات أو إضافة يدوية)
4. الطالب يدخل الكورس → يفتح شريط المحاضرة → يشاهد الفيديو / يحمّل الملفات / يمتحن في صفحة مستقلة
5. المستر: زر ⚙️ في `/home` → كلمة السر `123321` → لوحة الإشراف الكاملة
6. **بنوك الأسئلة**: تبويب "بنوك الأسئلة" → الصق مادة المنهج → حدد العدد → "ولّد الأسئلة" (فرنساوي فقط، من المنهج فقط) → راجع واحفظ. البنوك بتتجمع في مجموعات
7. **ربط امتحان ببنك**: في محرر المحتوى → "ربط ببنك أسئلة" → اختر البنك وعدد الأسئلة — كل طالب بياخد أسئلة عشوائية
8. **درجات الطلاب**: تبويب "درجات الطلاب" → فلتر بالبنك/الامتحان
9. **المتواجدون الآن**: تبويب مباشر بيتحدث كل 30 ثانية (تواجد = نبضة خلال آخر 5 دقايق)
10. **صورة الكورس**: في محرر الكورسات اختر من الصور الجاهزة أو الصق أي رابط صورة
